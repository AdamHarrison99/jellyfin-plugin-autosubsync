Safety

Discover and log everything, write nothing. Enabled by default on a fresh install.
The audio check always runs, and falls back to voice detection when the first pass cannot decide. When this is enabled, a subtitle neither pass can confidently decide on is left alone rather than written. Those are listed as "rejected as inconclusive"; untick this to retry them on the next sync. This also applies to downloaded subtitles via the acquire feature; disabling means they are written even if the audio check cannot confirm they are correct.

Scope

Tick the libraries to process. Nothing ticked means nothing runs.
Sidecar files next to your media.
Embedded tracks are extracted, synchronized, and written back as a separate subtitle file next to the media. The original file is never modified, so Jellyfin will list both the original embedded track and the synced one.
Off, a language a sidecar already covers is left alone and the subtitle list stays short. Turn this on to sync those tracks anyway — a "Signs & Songs" track usually carries the same language as the full subtitle, and this is what brings it back.
PGS, VobSub, and DVB tracks are pictures of text, which no alignment engine can read. Converting them by OCR produces a text subtitle that can then be synchronized. OCR is slow and never perfect; the result is written as a new file and the original track is left alone.
Off, an image track is skipped when you already have that language as text, which is minutes of OCR saved per track. Turn this on to convert every image track regardless. "Signs & Songs" and hearing-impaired tracks are always converted either way.
Strips [door creaks], (SIGHS), and speaker labels from the subtitles that are written. Lines that consist only of such a tag are dropped entirely.
Subtitle files that hold at least 85% the same text, styling, and format are collapsed to one. Only external files are removed; a track inside the video is never touched. Every removed file is copied to the backup vault first and is restored by "Roll back everything".
Comma-separated language codes (eng, spa or en, es). Two- and three-letter forms both work and can be mixed. Leave empty for all languages. Subtitles with an unknown language are always processed.

Output

Embedded tracks always become new sidecar files; this setting only affects subtitles that are already separate files. Overwriting always backs the original up first, into the plugin's own data folder and never beside your media. If the backup cannot be written, the original is left alone.

Throttling

0 = automatic: How many subtitles the full library scan, and new items as they arrive, are synced at once. Each sync reads the whole video file to analyse its audio, so the limit is often your storage rather than your CPU.

Automation

Runs as soon as a video appears in a selected library, instead of waiting for the next scheduled sync.
Makes a new subtitle show up in Jellyfin straight away, but can fire off a ton of media refreshes. Leave this off if the server is slow.


Actions

Starts the "Full Library Sync" scheduled task immediately. The task takes a moment to begin.
Puts every subtitle that failed or was rejected by the audio check back in the queue and starts a full library sync. Both are skipped on later scans, so use this after changing something that should change the outcome.

Danger zone

Restores every backed-up subtitle over the version this plugin wrote and deletes every subtitle file this plugin created. Your media files are never touched.
Forgets what has already been synchronized without changing any files. The next scan will re-examine everything. Backups are kept in the plugin's data folder and indexed only by this database — clearing it leaves them on disk with no way to restore them automatically.
